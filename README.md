# JNCO Trading & Contracting

Corporate website for **Jufal & Naif Obaid Al-Shammari Trading & Contracting Co.** — a Saudi Arabian heavy construction and contracting firm operating since 1973, delivering projects across roads, bridges, water systems, and industrial development.

## Stack

Static HTML / CSS / JavaScript. No build step.

## Local dev

```bash
# from this folder
python -m http.server 8080
# then visit http://localhost:8080
```

## Deploy

Connected to Cloudflare Pages — every push to `main` auto-deploys in ~30 seconds.
