# JNCO — Naif Obaid Al-Shammari Contracting Company

Corporate website for **Naif Obaid Al-Shammari Contracting Company** (شركة نايف عبيد الشمري للمقاولات) — a Saudi Arabian heavy construction and contracting firm operating since 1973, delivering projects across roads, bridges, water systems, and industrial development.

> Rebranded October 2026. The company was formerly *Jufal & Naif Obaid Al-Shammari Trading & Contracting Co.*

## Brand

| Token | Value | Use |
| --- | --- | --- |
| navy | `#002650` | `--brand-navy`, dark surfaces, text on amber |
| amber | `#f0a418` | `--brand-amber`, fills/glows, and accent text **on navy only** |
| deep amber | `#9c6207` | light-theme `--accent` — amber text on white (5.0:1) |

The logo amber is 1.96:1 on white, so amber *text* on light backgrounds uses the deep amber instead. `--on-accent` flips white/navy so button labels stay legible in both themes.

Marks live in `images/brand/` and are generated by `../jnco-profile/brand/make_assets.py`:
`logo-badge.png` (full roundel, loader), `logo-mark.png` (swoosh tile, nav/footer/favicon — the roundel is illegible below ~64px), `logo-wordmark*.png`, `favicon.png`, `apple-touch-icon.png`.

Bump the `?v=` query on `styles.css` / `script.js` in `index.html` when changing either file.

## Stack

Static HTML / CSS / JavaScript. No build step.

## Local dev

```bash
# from this folder
python -m http.server 8080
# then visit http://localhost:8080
```

Connected to Cloudflare Pages — every push to `main` auto-deploys in ~30 seconds.
